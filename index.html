      Sobre mim

      Transformo ideias em soluções digitais que funcionam

      Sou Frontend Web Developer e estudante de Licenciatura em Ciência da Computação no ISUTC. Gosto de entender como as coisas funcionam por dentro — do DOM à base de dados — e de transformar esse conhecimento em produtos úteis para pessoas reais.

      O meu foco é o frontend: interfaces limpas, acessíveis e responsivas com HTML, CSS, JavaScript e React. Trabalho também com bases de dados SQL (MySQL e PostgreSQL) e estou a aprofundar o backend com Java e Spring Boot.

      • Design responsivo (mobile first)
      • Manipulação do DOM e JavaScript moderno
      • Bases de dados relacionais (SQL)
      • Git e GitHub no dia-a-dia
